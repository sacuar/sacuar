Not every image needs an editor. **[Quick Photo Viewer](https://github.com/sacuar/quick_photo_viewer)** focuses on the simple task of opening local photos and moving through them quickly.

## Viewing first

The viewer includes folder navigation, thumbnail previews, arrow-key image navigation, rotation, fit-to-window and zoom. Its fullscreen and photo-only modes help keep the image prominent. The application runs locally; no account or cloud photo upload is needed.

## Windows and Ubuntu downloads

Version **2.9.6** has Windows and Ubuntu 24.04 x64 packages in [GitHub Releases](https://github.com/sacuar/quick_photo_viewer/releases/tag/v2.9.6). The Windows installer includes a verified-update workflow; Ubuntu uses a `.deb` and opens the official releases page when checking for updates.

A useful test is browsing a folder containing hundreds of full-resolution images while using the keyboard and fullscreen controls. Feedback about large directories and display scaling is welcome.
